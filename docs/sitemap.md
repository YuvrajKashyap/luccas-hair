- Logo or brand name links to Home.
- Services.
- Products.
- About.
- Contact.
- Primary CTA: Book Appointment.
- FAQ / Policies can live in the footer and be linked contextually from Book, Contact, and product-related sections.

## Footer Structure

## Notes For Mockup Generation

- Home should establish the dark cinematic premium direction and make booking visible in the first viewport.
- Services should prioritize scan-friendly comparison and a direct path to Book.
- Book should show the planned booking module area even if the platform remains TBD.
- Products should look commerce-ready while clearly allowing product details to remain TBD.
- Contact and FAQ / Policies can be planned as one combined mockup for Phase 3.
- Use one selected reference mockup per page once a direction is approved.

## Notes For Implementation Priority

1. Build shared layout, navigation, footer, and sticky booking CTA after mockups are locked.
2. Build Home and Services first because they support the booking decision.
3. Build Book next because it is the primary conversion surface.
4. Build Products with placeholder-safe data structures and `TBD` content.
5. Build About, Contact, and FAQ / Policies after client details are confirmed or safely marked as `TBD`.
