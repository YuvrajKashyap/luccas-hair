# Decision 0001: Project Name And Repo Direction

## Status

Accepted.

## Decision

The repository name is `luccas-hair`.

## Rationale

The repo name is clean, readable, and production-like. It avoids unnecessary prefixes, class labels, or temporary naming. This makes the project easier to present as real client-style work.

The public project title remains Lucca’s Hair. The README and documentation explain the client and business context clearly so the repo name can stay simple while still communicating the full project purpose.

## Impact

- The repository reads like a focused production website project.
- The docs carry the brand, UX, business, and technical context.
- Future contributors can understand the project without relying on hidden notes or informal context.
